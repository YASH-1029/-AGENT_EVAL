# AI Agent Evaluation System

An AI-powered refund customer support agent built with LangChain, LangGraph, and DeepEval.

## Project Objectives

- Implement a tool-using AI refund agent.
- Evaluate agent responses and execution behavior.
- Measure task completion, tool correctness, and answer quality.
- Investigate failure patterns and improve agent reliability.
- Benchmark alternative architectural decisions.

## Technology Stack

- Python 3.12
- LangChain and LangGraph
- DeepEval
- OpenAI API
- uv for dependency management
- pytest for automated tests

## Setup

1. Install uv and Python 3.12.
2. Run `uv sync --locked`.
3. Copy `.env.example` to `.env`.
4. Configure the required API credentials.
5. Run `uv run python --version`.
